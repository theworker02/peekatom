# peekatom

Peek structured JSON atom payloads without a heavyweight toolkit.

**Site:** https://theworker02.github.io/peekatom/

## Install / run

```bash
git clone https://github.com/theworker02/peekatom.git
cd peekatom
node src/cli.js
node --test
```
